## 3. T2-c 非字面函数复用登记行（包循环原因 + 漂移注释 + 终局审计复核点）

- **任务书字面**：FIX-PLAN §2 T2-c 写「恢复面复用保存面两门」（`validateTunnelFlow` ∈ {1,2}、`validateTunnelTrafficRatio` ∈ [0,100]）。
- **施工实际**：同合法集本地门镜像实现——新增 `validateImportedTunnelFlow` 与 `validateImportedTunnelTrafficRatio`（NaN/Inf 拒），合法集与文案口径与 handler 包两门逐字同集；`importTunnels` 门前置于链路预删之前，域外行 `rep.skip("tunnels")` + 逐行 `warnf` 点名（与 forwards status 门同形）。
- **不可字面复用的原因（包循环）**：handler 包依赖 repo 包，repo 直接引用 handler 的校验函数将成环；故字面函数复用不可行。
- **漂移注释**：函数注释已写明「两门任一漂移即视为本断言失效，须同步改动」——漂移即失效的失效条件已写死进代码注释。
- **关闭对象界定**：关闭对象是断言本身（四行跳过 + 点名全过），**不是字面复用**；若终局候选版审计坚持字面复用，须另立重构断言（把校验函数下移至共享包），不得以本批关闭冒充字面复用。——此行即终局审计复核点，审计时须就此给结论（接受镜像实现 / 另立重构断言二选一）。
- **关联登记**：T2-c 断言更新全集 = 无裁定点名更新（FIX-PLAN 断言逐字执行；夹具归一与 setup 值调整均非断言改动）。
