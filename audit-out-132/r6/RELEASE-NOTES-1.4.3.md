# FLMX 1.4.3 发版说明

## 版本概览

- 修复集成：`integrate-r6 @ 0ad8d74`（自 main `c2aad9e` 切出，10 批独立分支施工、10 合并提交零冲突零丢提交），以合并提交合入 main 后发版。
- 全量回归（合并树）：go-backend build/vet 通过、全量测试除 `internal/health` 的沙箱 fake-IP DNS 环境红一格（与基线同签名、隔离证据在发布报告）外全部通过；agent 两模块（go-gost、go-gost/x）build/测试全绿；前端 tsc 通过；check-contract-fields 与 check-doc-consistency 本地复跑 PASS；demo 走查 13 admin + 5 user 页全过；形状漂移自动检出 exit 0。
- 发版门真机验证（Lightsail 测试机，pristine 1.3.5 存量升级候选版）：**9 项全 PASS**——SS cipher 逐值表复跑 61/61、坏存量 SS 双面整份加载 17/17 + Xray `run -test` 3/3、grant 两条真机链 23/23、F-S01 两条计数管线 PG 契约 + companion 唯一索引在真 PG 逐字实跑 6/6 与 PendingDelete `-count=10` 10/10、备份导入矩阵真机 20/20、dashboard 列名逐字核、CI 三门禁本地等价复跑、哨兵回填在位、升级面常规 10/10，**放行发版**（报告 R6-RELEASE-GATE.md）。验后已恢复 pristine 并对账。

- 流程面两项入册（非产品行为变更，发版说明登记备查）：护栏 **N-37 正式入册**（探针类结论只认落盘原始日志 + 名单存档、摘要计数不得作裁定依据、后台日志矛盾整批作废前台重跑，任务书 catalog §1.6）；**台账面别计数新规固化**（条目分产品/文档/测试基建/流程基建四面别计数、收敛判据只计产品面，catalog §1.7）。

## 修复内容（按批次）

### 批 1 · 凭据族 SS 格总收口（R6X-001 / 002 / 003，含 R6X-024 前置）

施工前先重跑 SS method 候选全集 30 值的双二进制（sing-box + mihomo）逐值探针，与交叉复核裁定表（18 共同 / 1 单面 / 11 双拒）逐格一致、原始日志落盘存档后才写死白名单。新增 `ValidSSCipher` 合法集：**共同集 18 值**（`2022-blake3-aes-128-gcm`、`2022-blake3-aes-256-gcm`、`2022-blake3-chacha20-poly1305`、`aes-128-gcm`、`aes-192-gcm`、`aes-256-gcm`、`chacha20-ietf-poly1305`、`xchacha20-ietf-poly1305`、`aes-128-cfb`、`aes-192-cfb`、`aes-256-cfb`、`aes-128-ctr`、`aes-192-ctr`、`aes-256-ctr`、`chacha20-ietf`、`rc4-md5`、`none`、`xchacha20`）。双拒 11 值进口逐条拒绝、存量在 sing-box/Clash 双面整节点略过；单面值 `chacha20` 采分面处置（进口不拒、sing-box 面略过、Clash 面保留，见 BC-R6-01）。Clash 面补上 SS2022 key 逐段略过门，坏 key 存量不再毒化整份 Clash 订阅（BC-R6-02）；Xray 链式目标入口统一过存量谓词，坏存量不可再被选为链式目标。Surge/Loon/QX/URI 四面同批以同一谓词设门（无官方二进制，124 格恒标未验证）。三条关闭断言分开登记：已验关闭 132 格（001:120 + 002:4 + 003:8）。

### 批 2 · grant 生命周期两端对账（R6X-004 / 005）

删除点与豁免点两端同批收口：备份恢复的占位 grant 合并改为删前查组建来源标志、OR 提升保留行并以 warning 披露（删除点全集 11 处回勾零漏网）；sweep 豁免改逐条成员对应谓词，全假时按停用对裁定跳过恢复、错位 grant 计 warning——错位 grant 不再能屏蔽停用对裁定、已撤销授权不再复活（BC-R6-03）。005 与差集撤销墓碑无关、独立施工，未被墓碑缓做连带搁置。

### 批 3 · 备份导入矩阵收口（R6X-007 / 008 / 009 / 010 / 011）

按「导入全通道 × 保存面守卫全集」矩阵逐格收口：入站 Extra 谓词改为与手动导入（ParseImport）共用同一导出实现 `ValidateImportedProxy`（零第二份），坏代理对象的导入型入站行整行跳过；forwards 的 status=2（pending-delete）行按批裁定归一为 status=0 + warning 恢复（给由：侧表记账上下文不在备份内、另一案只能伪造记账且会重置 24h 上限；下限「可见或可终删」达标），非法 status 跳过；跳过回执补行身份（#{id} {name}）与错误摘要；计量伴生入站不再可经导入分配给用户、伴生行整行跳过 + 计数 + warning；backupImport 同步触发 reconcileSSMetering，恢复后伴生即时物化（BC-R6-04）。附带同型补齐（不计关闭数）：删入站失败路径的伴生删除后置至主删成功之后。

### 批 4 · 计费/显示口径（R6X-006 / 016 / 017）

## 行为变更（BC-R6-01…06）与可转发文案

- **BC-R6-01**（R6X-001）：SS cipher 合法集收口：双客户端均不接受的 11 个方法名自本版起不可导入、存量整节点略过；单面方法 `chacha20` 从 sing-box 订阅消失（Clash 面保留）；合法集 18 值行为不变。自建入站不受影响（保存面方法目录本就约束）。
  可转发：本次更新后，使用了非法加密方法名的 Shadowsocks 导入节点会被拒绝或在订阅中跳过；chacha20 方法的节点在 sing-box 订阅中不再出现（Clash 订阅不受影响），其余合法方法行为不变。
- **BC-R6-02**（R6X-002/003）：SS2022 坏 key 存量在 Clash 系订阅改为整节点略过（不再毒化整份订阅、与 sing-box 面一致）；坏存量节点不可再被选为 Xray 链式目标、已引用者下发时报错。
  可转发：本次更新后，密钥损坏的 Shadowsocks 2022 存量节点会在 Clash 订阅中被自动跳过，不再导致整份订阅失效；这类节点也不能再用作链式代理目标。
- **BC-R6-03**（R6X-004/005）：授权台账口径修正：备份恢复合并 grant 时组建来源标志不再静默丢失；错位 grant 不再能屏蔽停用对裁定，此类行按停用对跳过恢复（合法备份与合法台账导入终态不变）。
  可转发：本次更新后，恢复备份时来源标志不完整的授权记录会被明示提示；位置错位的授权不再能让已停用的分组权限对被恢复，正常备份不受影响。
- **BC-R6-04**（R6X-007/008/011；009 回执增补、010 生效时点提前同批带过）：备份恢复收口：携带坏代理对象的导入型入站行改为整行跳过 + 回执明示；pending-delete 状态的转发恢复后归一为暂停口径、可见可删；计量伴生入站不再可经导入分配给用户。
  可转发：恢复备份时，配置损坏的入站会被整行跳过并在回执中点名；处于待删除状态的转发恢复后可见可删；计量专用入口不能再通过导入分配给用户。正常备份不受影响。
- **BC-R6-05**（R6X-014/015）：存量异常状态账号（status 非 0/1）口径属实化：login 由「签发不可用 token」改为明确拒绝、sub_store 不再放行；合法状态行为零变更。附带：UDP 诊断对硬拒集目标由误报可达改为明确拒绝。
  可转发：本次更新后，状态异常的账号登录会被明确拒绝（此前会拿到一个不可用的登录态）；UDP 诊断对明确禁止的目标不再误报可达。正常账号不受影响。
- **BC-R6-06**（R6X-006/017/012）：展示/执法口径补齐：dashboard 转发卡「计费」列改名「总流量」（数值本为原始流量合计、配额执法从未受影响）；限速规则变更改为即时生效；gh_mirror 长期故障下超 24h 旧副本改为报错。
  可转发：转发卡上的「计费」列已改名「总流量」，数值口径不变（一直是原始流量合计，流量配额扣减不受影响）；限速规则改完立即生效；镜像源长期不可用时超时的旧版本信息会明确报错而不是悄悄沿用。

## 已知限制

- **Xray 本体 SS 方法集窄于面板合法集（留 R7 裁定）**：共同集 18 值中 10 值被 Xray 本体 exit 23 拒（Xray 的 SS 方法集本就窄于 sing-box/mihomo）——本轮两条关闭断言（进口谓词 + 链式面守卫）已逐字达标，该观察不在断言字面内；是否给 Xray 链式面加「Xray 子集门」由 R7 交叉复核裁定，本版不扩面。
- **四面未验证（124 格）**：Surge / Loon / QX / URI 四面的 SS 格守卫已以同一谓词设门、代码断言在案，但无官方二进制/客户端可实测，恒标未验证；SIP023 多段在该四面的残余口径同此。
- **差集撤销墓碑（沿袭缓做）**：撤销墓碑表三触发条件本轮逐条对账均未满足，维持缓做；过渡 warning 在位（R6 门内复验通过）。
- **SubTraffic.since fixtures 漂移一格与任务书 catalog §1 指针刷新**：均已登记留 R7，不影响本版结论。
