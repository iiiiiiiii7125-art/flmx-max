# FLMX 1.3.5 发版说明

R1 全量审计修复版：以 1.3.4 为基线完成新一轮「基线 → 12 域并发审计 → 交叉复核裁定 → 10 批修复 → 集成全量回归 → 发版门真机复验」循环，本版是该轮的全部修复成果。用户已预授权按交叉复核推荐口径执行（含全部行为变更项）。

## 版本概览

- 审计总账（R1-X-ledger 去重合并后）：**P0 = 0 / P1 = 3 / P2 = 17 / P3 = 34，合计 54 条，54/54 全部关闭**；交叉复核裁定 24 条（V-01…V-24）+ 护栏修订 4 项（G-1…G-4，落在审计基建文本）全部落地；本轮主旋律仍是「修A漏B」——多条缺陷是同一修复族在兄弟路径上的漏网（限速回退、分组撤销、白名单接线、通知置位、导入校验各一族）。
- 修复 10 批共 71 个修复提交 + 集成收口，全量回归全绿：go-backend 16 包全 ok（零 FAIL）、go-gost 与 go-gost/x（27 包）全 ok、前端 tsc 0 错误、vite build 产物 Service Worker 含 skipWaiting + clientsClaim（死缓存修复无回退）、脚本测试套件与文档一致性检查双 PASS。基线已知 flake `TestPerUserSessionLimit` 已在本轮 deflake 治理（连跑验收全绿）。
- 发版门真机复验（测试机原地升级）：9/9 PASS——存量计数升级前后完全一致、离线删隧道 + 节点重连零残留、分组撤销三路径、监控写权收回四入口 403、限速回退禁用即解除、卸载内核守卫、幂等键、死缓存三面、计费入账精确对账。
- 行为变更共 14 条单列于下节（BC-01…BC-14），每条附一行可直接转发的通知文案；无破坏性数据迁移，存量订阅链接、备份格式保持兼容。

## 修复内容（按批次）

### 批次 1 · 限速执法收口

- **P2**：user-tunnel 级限速解析补 `status=1` 过滤——已禁用的限速规则经回退路径继续生效的缺陷关闭（见 BC-07）；`speed=0` 的规则不再被当作硬限速 0；realm 侧「不支持限速」告警补齐 UT 级回退场景，不再漏报。

### 批次 2 · 分组授权完整性

- **P1**：分组授权撤销补齐剩余三条路径——用户编辑页改 groupIds、groupTunnelAssign 换隧道组成员、删除用户组/隧道组，此前只补发不撤销，现与既有两路径同口径撤销组建授权并清理其转发（见 BC-02）；
- userUpdate 的分组替换改事务化：中途失败成员保持原样并报错，不再「清空全部分组仍回成功」；分组授权展开改为逐条回执：部分失败列明、全失败报错，不再静默半成回「分配成功」；批量分配中途失败整批补偿回滚 + 重下发恢复；
- 建/改用户校验 groupIds 存在性（见 BC-11）。

### 批次 3 · 删除路径与白名单接线

- **P1**：删隧道在入口节点离线时改走待清理语义：删库立即生效、gost 登记待清理（重连对账撤监听）、nft 走既有 pending-delete 台账；节点在线但清理真实失败仍中止报错，防孤儿目标不丢（见 BC-01）；
- 卸载内核补 `chainInUseMessage` 同族守卫：被跨内核/跨节点链式引用的入站不再被静默级联删除（见 BC-06）；
- 入站白名单刷新补接隧道编辑（改入口/出口）与转发页删转发（含强制删/批量删）两处漏接路径：新出口 IP 不再被白名单丢弃、旧节点 IP 不再残留放行；
- 落地型中转「出口必须单出口」在隧道编辑时复检，转发换隧道/删除迁移重算 RemoteAddr（见 BC-05）。

### 批次 4 · 监控与通知

- **P1**：服务监控写入口（create/update/delete/run）改仅管理员——被授予查看权的用户此前实际拥有完全监控权，与文档只读承诺正面冲突，本版按文档改代码（见 BC-03）；
- 内核错误与回程变化两类通知补齐「发送成功才置位」：发送失败回滚状态/比对基准，下一轮自动补发，不再永久丢失（八事件至此全覆盖）；
- 文档修订：monitoring.md 删除不存在的 HTTP 监控类型与「连续失败触发通知事件」两处承诺（批次 9）。

### 批次 5 · 导入与抓取安全

- **P2**：导入主机校验由只拦字面量改为解析后逐 IP 判定：`localhost`、整数/十六进制/八进制/简写 IP 全部拒绝，与抓取侧 SecureFetch 同口径（见 BC-04）；
- 元数据硬黑名单补全：阿里云 100.100.100.200 在任何配置下恒拒，NAT64 翻译形态的内嵌元数据/私网地址同样拒绝，公网 NAT64 不受影响；
- 备份导入 `importUserSubscriptions` 补用户存在性校验：悬空分配改计 skipped、零落库（见 BC-08）；空 token 订阅同口径计 skipped。

### 批次 6 · 脚本与 CI

- **P2**：install.sh 更新判活与面板路径对齐为两次采样 + PID 稳定，短时存活的坏/flap 二进制不再被判成功、`.bak` 回滚源不再被误删；
- install.sh 脚本更新新增版本方向校验，防静默降级（见 BC-09）；菜单操作失败退出码改非 0（见 BC-12）；
- publish-skill 删除其自建 GitHub Release 步：Release 由主发版流唯一创建，npm 步转绿后不再有双 Release 冲突面；主发版流内不可达的死 job 一并移除。

### 批次 7 · 订阅渲染与前端契约

- 订阅流水线 normalize 补齐 ChainLandingNames/ChainRelayNames（修剪 + 条数/长度上限），带空格的名字不再落库后永不命中、链式静默失效；
- `format=stash` 的节点计数与拉取侧同口径映射 Clash，不再回落 base64 导致两入口数字不一致；
- 订阅脚本 20000 上限改按字符计数（保存/执行两侧同改，见 BC-10）；legacy 路径订阅重置补凭据全轮换，旧配置真正失效；
- 订阅重置的共用凭据例外入文档与重置弹窗提示：SS/Snell/导入节点共用凭据的入站不随单个订阅重置失效（见升级注意事项）；
- 更新入站省略 port 改 presence 保留语义，不再被静默改派随机端口（仅 API/技能包调用方受益，UI 恒带端口）；
- 前端：`UserMutationPayload` 的 `password` 字段改与后端一致的 `pwd`，消除类型契约漂移；三处轮询（节点列表、监控结果、内核列表）补旧响应覆盖守卫，慢网络下旧快照不再覆盖新数据。

### 批次 8 · 横切：事务 / 并发 / 上下文 / 幂等

## 行为变更（逐条附可转发通知文案）

1. **BC-01 删隧道离线立即生效**：删隧道在挂有转发且入口节点离线时不再被中止：删库立即生效，节点侧残留由重连对账清理（gost 撤监听、nft 走待删台账）；节点在线但清理真实失败仍报错中止。
> 本版起，入口节点离线时删除隧道也会立即生效，不再被拦截；节点上的残留会在节点重连后自动清理。在线但清理失败的情况仍会报错中止。
2. **BC-02 分组撤销真正生效（重点）**：移出分组/换隧道组成员/删组将撤销组建授权并清理其转发；升级后首次成员变更会追溯撤销历史残留组建授权。手工单独授予的授权不受影响。
> 本版起，把用户移出分组、更换隧道组成员或删除分组，都会真正撤销该分组发放的隧道授权并清理其转发；升级后第一次发生分组变更时，历史残留的分组授权也会一并撤销。手工单独授予的授权不受影响。
3. **BC-03 监控查看权限回归只读（重点）**：被授权用户不再能新建/修改/删除/立即执行服务监控，写操作仅管理员（监控四写入口改管理员校验，读入口不变）。
> 本版起，服务监控的「查看权限」回归只读：被授权用户只能查看，不能新建、修改、删除或立即执行监控；这些操作仅管理员可进行。
4. **BC-04 导入接受面收紧**：导入主机校验改解析后判定，`localhost` 与整数/十六进制/八进制/简写 IP 由放行变逐条拒绝。
> 本版起，导入节点/订阅源时的主机校验收紧：localhost 以及整数、十六进制、八进制、简写等非规范 IP 写法将被拒绝；此前用这类写法导入的条目如需编辑保存，请先改成规范 IP 或域名。
5. **BC-05 隧道编辑新增拒绝 + 转发迁移重算**：落地型中转的出口集变更在编辑时复检（不合规拒绝）；转发换隧道/随隧道删除迁移改为重算 RemoteAddr，不再静默指向错误出口。
> 本版起，落地型中转隧道的出口变更会在编辑时被校验，不合规的变更将被拒绝；转发更换隧道或迁移时会重新计算远程地址，不再静默指向错误出口。
6. **BC-06 卸载内核守卫**：卸载被跨节点引用的内核由恒可执行变为默认拒绝（列明引用方）；Force 可放行，响应回传被断引用清单，前端弹窗同步展示。
> 本版起，卸载正被其他入站链式引用的内核将默认被拒绝，并会列明引用方；确需卸载可强制执行，系统会回传被断开的引用清单。
7. **BC-07 已禁用限速不再生效**：已禁用的 user-tunnel 级限速规则自下次同步起不再被引用生效（恢复 O2-005 既定语义；删除与禁用行为一致）。
> 本版起，已禁用的用户隧道级限速规则自下次同步起不再生效（禁用即解除，与删除行为一致）。
8. **BC-08 备份导入回执变诚实**：备份导入中用户不存在的悬空订阅分配由计 imported 改计 skipped，且不再落库。
> 本版起，备份导入时目标用户不存在的订阅分配将计入「跳过」而非「已导入」，且不会落库；回执数字与实际导入结果一致。
9. **BC-09 install.sh 更新防降级**：install.sh 脚本更新新增版本方向校验，目标低于现装版本时在下载前拒绝。
> 本版起，用 install.sh 更新节点时会校验版本方向：目标版本低于现装版本将被拒绝，不再静默降级；确需降级请手工处理。
10. **BC-10 订阅脚本按字符计数**：订阅脚本 20000 上限由按字节改按字符计数（保存与执行两侧同改），多字节脚本可用长度放宽至文档承诺值。
> 本版起，订阅脚本的长度上限按字符计数（20000 字符），含大量中文注释的脚本不会再被提前拒绝。
11. **BC-11 组 ID 存在性校验**：建/改用户传不存在的组 ID 由静默成功变报错，且零落行。
> 本版起，新建或编辑用户时传入不存在的用户组 ID 将直接报错，不再静默保存为无效的成员关系。
12. **BC-12 install.sh 失败退出码**：install.sh 菜单操作失败的退出码由恒 0 变非 0（仅退出码，屏显不变）。
> 本版起，install.sh 的菜单操作失败时退出码为非 0（屏幕输出不变）；用脚本或自动化调用的请按退出码判断成败。
13. **BC-13 创建类接口 Idempotency-Key**：创建类接口新增可选 `Idempotency-Key` 请求头语义：不带键行为不变；带同一键重复提交只建一条并回放首次结果。
> 本版起，创建类接口支持可选的 Idempotency-Key 请求头：带同一个 key 重复提交只会创建一次并返回首次结果，适合脚本重试防重复创建；不带 key 的行为与旧版完全一致。
14. **BC-14 转发校验 fail-closed**：转发 create/update 在入口节点读取失败时由跳过校验落库变整条报错（影响面仅 DB 瞬时故障窗口）。
> 本版起，创建或更新转发时若入口节点信息读取失败将整条报错，不再跳过校验直接保存（仅影响数据库瞬时故障的极短窗口）。
