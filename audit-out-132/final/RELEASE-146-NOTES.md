## 新增：备份上传 GitHub Gist

> 新增“备份上传 GitHub Gist”：可把面板全量备份加密后存到你个人 GitHub 账号的私密 Gist，并按需定时自动上传。
>
> - 默认关闭：不填令牌、或间隔选“关闭”时，面板不会向外发任何备份；只有你主动保存并开启后才会上传。
> - 需要你个人 GitHub 账号的 classic token（勾选 gist 权限）。令牌只存在面板配置里，不进备份文件；保存时会先校验令牌可用。
> - 加密必填：必须设置加密密码才能保存与上传，留空密码会被拒绝，不存在明文上传的选项。密码同样只存面板配置、不进备份；丢了上传时的密码，Gist 上的加密备份永久无法恢复，请务必另外保管好密码。
> - 私密 Gist 只表示不公开列出，拿到链接的人仍能看到备份内容——加密是真正的保护层，不要把 Gist 链接随意外发。
> - 在面板侧清除令牌、断开关联，不会删除 GitHub 上的 Gist 及其历史版本；要彻底清除须登录 GitHub 网页端手动删除该 Gist。

技术注记：5 端点（status/save/upload/versions/restore，仅管理员）；恢复走与本地文件导入同一尾链（含 FINAL-P2-1 七段谓词），恢复段为我方 16 段全集；恢复前自动备份失败按我方 O7-010 继续导入；路由钉死值 202；凭据进 sensitive + systemManaged 双表。
