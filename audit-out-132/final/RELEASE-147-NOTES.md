# FLMX 1.4.7 发版说明（随分支 release-1.4.7；打 tag 由父代理验后执行）

- 版本：**1.4.7**（纯数字 tag，禁 `v` 前缀）。
- 内容基线：`b65b801` 调优集成树 = 1.4.6（Gist）+ 服务器调优移植（上游 flyx 3.3.42）+ 一键测算探测。
- 发布依据：调优变更面重审新增产品 P0/P1/P2=0；调优发版门 5 项全 PASS、无 FAIL；集成回归产品失败 0（唯一红为已知沙箱 fake-IP 环境红）。
- 升级顺序（必读）：**先停 agent → 换面板 → 再启 agent**（避 gost.json 服务重复致 agent 首启失败）。

## 行为变更（BC，可转发文案逐条）

> 服务器调优新增“按线路算缓冲区”：节点调优弹窗新增带宽（Mbps）与延迟（ms）两个输入（范围 1–100000 / 1–2000，两个都填才算一条线路参数，只填其一或超出范围时面板与 agent 都会拒绝）。agent 按带宽 × 延迟（BDP）算出单连接缓冲区上限：BDP = 带宽 × 1_000_000 / 8 × 延迟 / 1000（字节），上限 = 2 × BDP + 2 MiB，下限 4 MiB，上限受本机内存封顶（内存 / 32，上限 256 MiB）；连接起始缓冲 1 MiB；tcp_mem 按内存页数的 1/16、1/8、1/4 三档。不填线路参数时，agent 先取上次应用值，无上次值时用默认 **1000 Mbps / 150 ms**。生效值写入 `/proc/sys` 并持久化到 `/etc/sysctl.d/99-flmx-tuning.conf`（旧名 `99-flvx-tuning.conf` 残留会在应用时清理），应用前原值有备份、恢复默认时写回。

> 旧 agent 自动降级（无版本号硬门）：调优能力判定只看 agent 状态回包带不带 `params`（实际生效的线路参数），不比较 agent 版本号。旧 agent 不显示带宽 / 延迟输入框、不发送线路参数，其余调优功能照常可用，按旧固定值工作（缓冲区组 64 MiB 等）；即使新面板误把线路参数发给旧 agent，旧 agent 也会按 JSON 语义丢弃未知字段。升级后首次应用若不填线路参数，agent 会用默认 1000 Mbps / 150 ms 计算，不再是旧固定值 64 MiB，请在首次应用前先填入该节点的真实带宽与延迟。

> 一键测算（建议值回填，不自动应用）：调优弹窗新增一键测算，探测结果只回填到你尚未手动改过的输入框，采纳建议值仍须显式点击应用；探测本身绝不写盘、不改 sysctl。延迟取节点已建立 TCP 连接的内核 RTT 中位数，取不到时明确报不可用并回落默认值；带宽默认不测速，只有当你提供测速地址时才对该地址做短时测速（10 秒 / 64 MiB 上限），未提供地址时明确报不可用并回落默认值；每腿独立回落且必明示警告。

> 出站端口范围提醒：勾选高并发队列组会把出站临时端口范围钉死为 `10000–65535`。若节点上有出站连接依赖 10000 以下临时端口的特殊服务，应用该组前请先确认——这是上游同提交带来的行为，不是 FLMX 自创。

## 诚实披露（O-1，必读）

> 一键测算的 sock_diag 内核 RTT 中位数腿在真机与沙箱均未走通成功路径：在真实节点（存在 agent、SSH、转发等真实 TCP 连接）上探测仍报中位数不可用、回落默认值，设计回落（默认值 + 明示警告 + 不编造数值）实测工作，但“中位数成功路径”至今在任何机器上均未验证。发版说明不宣称中位数已验；该腿可用时，参考 RTT（到面板的 TCP 建连 RTT）在实测中工作，可作延迟参考。

## 已知项（TUN-P3-1，不阻塞）

- 出站端口范围 10000–65535 的真机回归覆盖在重审时未证；发版门已点名覆盖该项。仅影响依赖 10000 以下临时端口出站的特殊服务，绑定固定端口的服务不受影响。

## 不在本版

- 其余 1.4.6 内容（Gist 备份等）已在 1.4.6 发布，本版为其上的调优增量。
