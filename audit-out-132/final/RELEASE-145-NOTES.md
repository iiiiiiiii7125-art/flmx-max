# FLMX 1.4.5 发版说明（草稿，随分支 release-1.4.5；打 tag 由父代理验后执行）

- 版本：**1.4.5**（纯数字 tag，禁 `v` 前缀）。
- 内容基线：`047e1ef` 树 = R8–R13 全部修复 + FINAL-P2-1 修复。**Gist 备份移植不在本版**，顺延下一版 1.4.6（见 `RELEASE-146-GIST-DRAFT.md`）。
- 发布依据：终局候选版审计新增产品 P0/P1=0；R13 靶向门 8/8 PASS；FINAL-P2-1 门复验放行（真机 + 恢复 PASS，本地回归在并行负载下默认超时 434.6s 通过）。
- 升级顺序（必读）：**先停 agent → 换面板 → 再启 agent**（避 gost.json 服务重复致 agent 首启失败）。

## 行为变更（BC，可转发文案逐条）

### R8（2 条）

> VLESS 加密（ENC）的 Xray 最低版本要求更正：最低版本由 25.6.8 更正为 **25.9.5**。原下限写错——Xray 25.6.8 至 25.8.29 实际无法加载 ENC 配置，在该版本区间按面板此前提示使用 ENC，配置下发会加载失败。存量节点 Xray 在 25.6.8–25.8.29 区间者，升级后其 ENC 入站的保存/换版校验将被拒绝，请先将该节点 Xray 升级至 25.9.5 及以上再操作 ENC；非 ENC 功能不受影响，Xray 已在 25.9.5 及以上的节点不受影响。

> Shadowsocks 单面方法扩收：以下 5 个仅 mihomo 支持的加密方法——`aes-128-gcm-siv`、`aes-256-gcm-siv`、`chacha8-ietf-poly1305`、`aes-128-ccm`、`aes-256-ccm`——此前在面板进口被直接拒绝，本次改为与 chacha20 同款的分面待遇：可以导入、Clash 系订阅中保留、sing-box 面与链式面略过/拒绝。此前被拒的此类节点可重新导入。

### R9（5 条）

> 若您曾通过接口将流量限额设为 0，本版起 0 表示不限额，此前因此被暂停的转发将自动恢复。

> 经 sing-box 配置导入的 VLESS 加密节点此前会被当作普通 VLESS 导入（加密参数丢失、节点不可用），现已按加密节点正常导入；sing-box 格式订阅中该类节点将按既有口径不再出现（加密节点仅在 Clash/通用格式下发）。

> VLESS 加密串文法收紧：不符合 Xray 官方文法的异源加密串（填充段形态非法等）在导入/链式时将被拒绝；Xray 官方工具与面板自产的加密串不受影响。

> Naive 链式目标新增版本门：sing-box 低于 1.13 的节点不能再以 Naive 节点为链式落地（此前保存成功但节点必然整单失败），保存/下发时将直接点名报错；升级节点 sing-box 至 1.13 及以上即可。

> 备份恢复收口补格：备份中入站的白名单附加地址清单（WhitelistExtra）恢复时将按保存面同口径校验，非法条目将被跳过并在回执中披露（此前逐字恢复、无提示）。

### R10（7 条，成文可转发文案）

> 导入枚举字段收口：异源大写或非法枚举值（client-fingerprint、xhttp mode、SS obfs mode）在导入时规范化为合法小写或逐条拒绝；此前可入库但令 sing-box/Clash 订阅整表无法加载的节点不再入库。规范配置不受影响。

> ENC 文法按 Xray/mihomo 实测集对齐：一格收紧（`+`11 位数字（token 12 字符）不再放行）、两格放宽（4 元素填充组、首组第 4 数起含 0 不再误拒）。官方与面板自产的加密串不受影响。

> 订阅头总量口径修正：以 MB/亚 GB 设限的用户，订阅客户端显示总量由向上取整的整 GB 改为与面板执法一致的精确值（数值变小、与实际限额一致）。

> 前端显示修正：限额为 0（不限额）的用户/隧道不再显示「0 B」、改显「无限制」；此类行可直接编辑保存。

> 配置读取收口：未分类的新配置键默认按敏感处理、普通用户不可读；现行配置键读取行为不变。

> Surge/Loon 导入修正：VMess 行的 `encrypt-method` 不再被静默丢弃，指定 security 按原值生效（此前恒落 auto）。

> 未配置 Turnstile 时 captcha verify 的本地 "ok" 回退关闭、端点返回未启用语义；已配置 Turnstile 的部署不受影响。

### R11（7 条，成文可转发文案）

> 经 API 或备份恢复写入的 XHTTP 入站 Mode：大小写变体（如 `AUTO`）自动愈合为规范值，集外值（如 `bogus`）改为保存时报错拒绝（此前原样落库且可致订阅整表/内核整单不可加载）。

> 存量坏节点在 URI / Surge / Loon / Quantumult X 订阅面由「下发坏链/坏行」改为整节点略过（与其余订阅面既有口径对齐）；合法节点产物不变。

> 带首尾空白的 ENC 串节点在 Clash 订阅中下发为修剪后形态（此前可致整份 Clash 订阅不可加载）；存储值不变。

> ENC 文法与客户端实测对齐：填充组含尾随/重复破折号的形态由拒绝改为放行；组首破折号等形态仍拒。

> 隧道创建/编辑新增校验：流量倍率超出 [0,100]、计费方向不在 {单向,双向} 时报错拒绝（此前可落库且各面读法不一致）。

> Snell v6 节点经 sing-box JSON / Surge 行导入时，`mode` 大小写变体由静默丢弃改为保留规范值（整形语义不再丢失）。

> 月度流量重置改为到期补跑：面板在重置日停机错过重置的，恢复运行后首次日维护即补重置一次（此前整月不重置）；重置日当日在跑的行为不变。一次性局限注记：标记列诞生前已错过上月的存量行，等到当月重置时刻才补跑、仅升级月一次性。

### R12（1 条）

> 本次更新订正了面板中隧道计费方向的显示标签：此前 Flow 为域外值（主要为联邦建隧道产生的存量行）在本人卡片上显示为「双向计费」，订正后显示为「未知」；联邦新建隧道改按单向计费建值。计费入账口径本身未变（此前即按单向入账），无资损，无需任何操作。

### R13（2 条，复核采用）

> 备份恢复后，在线节点的转发数据面现在会与正常写路径一致自动重推：恢复出的转发服务、nft 规则与中转地址将按备份内容重新下发，无需您手工再编辑或重连节点。注意：重推过程中在线服务可能短暂重建，属一次性恢复行为；若个别节点重推失败，恢复回执中会列出失败节点，不会再静默报成功。无迁移、无需您额外操作。

> 备份导出/导入时，未知类型现在会直接报错并点名未知值，不再静默成功。面板内正常操作不受影响（面板类型清单与后端一致）；若您直接调用 API 且类型清单中含有拼错或未知的类型，请先修正清单，否则调用将返回报错。无迁移。
