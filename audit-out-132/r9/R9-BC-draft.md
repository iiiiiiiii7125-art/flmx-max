## BC-R9-01（覆盖 R9X-001，流量限额 0 值语义订正）

内容（FIX-PLAN §2 逐字）：流量限额 0 值语义订正：经 API 将用户/隧道流量限额设为 0 的，此前会被当作零配额（恒暂停全部转发、开启转发被拒），现按「不限额」执行；已存量为 0 的用户/隧道升级后自动恢复正常转发。

**可转发文案定稿全文（逐字取 FIX-PLAN §2）：**

> 若您曾通过接口将流量限额设为 0，本版起 0 表示不限额，此前因此被暂停的转发将自动恢复。

## BC-R9-02（覆盖 R9X-002，sing-box 导入 VLESS 加密节点保真）

内容（FIX-PLAN §2）：sing-box 配置导入的 VLESS 加密节点此前会被当作普通 VLESS 导入（加密参数丢失、节点不可用），现已按加密节点正常导入并校验；sing-box 格式订阅中该类节点将按既有口径不再出现（加密节点仅在 Clash/通用格式下发）。

**可转发文案定稿全文（逐字取 `R9-H-report.md` §一建议稿）：**

> 经 sing-box 配置导入的 VLESS 加密节点此前会被当作普通 VLESS 导入（加密参数丢失、节点不可用），现已按加密节点正常导入；sing-box 格式订阅中该类节点将按既有口径不再出现（加密节点仅在 Clash/通用格式下发）。
