S 改名：FLVX → FLMX（含仓库 flvx-max → flmx-max）（2026-10-20，版本 1.0.24） ​

原则：展示与新数据全用新名；凡硬改会断存量（.env、已发链接、磁盘状态、 内核活规则）的，一律双读/双发/迁移清理，过渡完成面与新名一致。

后端（盘点 A：go-backend + go-gost，58 文件命中） ​

直接改 ​

  • 展示：app_name 种子与兜底（repository.go:529、kernel_relay.go:653、 notify.go:118）现行值 FLVX-MAX → FLMX；Passkey RPDisplayName（passkey.go:62）
  • 日志前缀 [flvx]（go-gost/x/kernel manager/geodata、socket/process）、 nft runner 的 "FLVX rules" 文案
  • User-Agent flvx-panel/1.0 → flmx-panel/1.0（secure_fetch.go:258）
  • FLVX-PING 探测载荷 → FLMX-PING（接收方不校验内容）
  • 仓库常量：handler/upgrade.go:26、go-gost/x/socket/websocket_reporter.go:1445 → iiiiiiiii7125-art/flmx-max（测试 system_upgrade_test.go 同步）

双读兼容（新名优先、旧名兜底） ​

  • 环境变量 6 个运行时 + 1 个测试专用：FLMX_TRUSTED_PROXY_HOPS、 FLMX_FETCH_ALLOW_PRIVATE_NETWORKS、FLMX_FETCH_PRIVATE_ALLOWLIST、 FLMX_FEDERATION_TRUSTED_PROXIES、FLMX_WEBAUTHN_ORIGIN（后端）； FLMX_KERNEL_DIR（agent）；FLVX_POSTGRES_TEST_DSN（CI/测试，直接改名）
  • 订阅签名：新增 flmx-subsig-v3 生成新链接；校验 v3→v2→v1 三代通吃 （user_inbound.go），存量链接不断
  • 流量上报头：agent 双发 X-Flmx-Seq + X-Flvx-Seq；面板先读新头回退旧头
  • agent seq 文件 flvx_agent_seq.json → flmx_agent_seq.json，新文件缺失时 读旧文件迁移（防 seq 重置导致重复计账）
  • 内核用户标识：渲染改 u%d@flmx / flmx-u%d（users.go:17,163），流量 归属解析双认 flmx/flmx 两种前缀，过渡期新旧配置并存不丢账

改名 + 清理 legacy（防残留生效） ​

  • nft 表：面板 inet flvx → inet flmx、节点 flvx_kernel → flmx_kernel； 应用/启动路径显式删除 legacy 表，否则旧表在内核继续生效
  • sysctl 调优文件 /etc/sysctl.d/99-flvx-tuning.conf → 99-flmx-tuning.conf， 写入时顺带删除旧文件（99-flmx 字典序在前，残留旧文件会静默覆盖新值）
  • 部署目录探测：/opt/flmx-panel 优先、/opt/flvx-panel 兜底 （system_upgrade.go:28，存量面板装在旧目录）
  • 升级状态文件 .flvx_upgrade_status.json → .flmx_upgrade_status.json （Go 与生成的 helper 脚本同改；读时回退旧名）
  • GH 镜像缓存目录 flvx-github-cache → flmx-github-cache（旧缓存孤儿无害）
  • 升级 helper 临时名 flvx-upgrade-helper-%d → flmx-…
