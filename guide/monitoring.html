监控 ​

监控分三类：节点监控、服务监控、隧道质量。入口按角色分开：

  • 管理员没有独立的「监控」菜单——从 节点 页逐个节点打开监控（实时指标、历史曲线、该节点的服务监控），隧道质量从 中转 页的 质量 标签看；直接访问 /monitor 会跳回节点页。
  • 被授予监控权限的普通用户有独立的 监控 总览页，跨节点看状态（见下「监控权限」）。

本文只讲监控面本身；哪些异常会经 通知 推送，以通知页的事件清单为准。

节点监控 ​

按节点列出在线状态与运行指标（连接状态、版本、流量与资源占用等）。管理员在节点列表里点开单个节点的监控看明细；普通用户在总览页跨节点扫一遍有没有异常。

服务监控 ​

对任意目标做定时连通性探测，适合盯落地机端口、第三方服务或某个 IP 是否可达：

  • 类型：TCP（端口连通）、ICMP（ping）；
  • 经节点探测：TCP / ICMP 可以指定由某个节点上的 agent 发起探测，测的是「从该节点出发」的连通性；TCP 可不指定节点（面板侧探测）；ICMP 必须指定执行节点；
  • 间隔与超时：每项可单独设探测间隔与超时（超时最大 60 秒）；可以随时 立即执行 一次，不等下一轮；
  • 启用 / 停用：停用的探测不再执行，历史结果保留；停用只停调度，立即执行对停用项同样可用；
  • 探测结果（成功/失败、耗时）留存并可回看。

隧道质量 ​

逐跳探测每条隧道的连通与延迟（入口 → 中间跳 → 出口），定位多跳线路里是哪一段出问题。隧道质量探测默认开启，探测间隔在 网站配置 的监控设置里可调。

监控权限 ​

管理员不需要授权，直接从节点页 / 中转页进入。普通用户默认没有监控入口：管理员在 用户 页给指定用户授予监控权限后，该用户菜单里出现 监控 总览页，能看状态，但不能改监控配置、不能执行管理操作。

数据保留 ​

监控类数据（探测结果、质量样本等）的保留天数在 网站配置 里可设，过期数据自动清理。需要长期留档的指标请用每日汇总通知或自行导出。
