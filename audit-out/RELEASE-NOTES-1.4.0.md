# FLMX 1.4.0 发版说明

上游 flyx 3.3.30–3.3.33 可移植项全量移植版（对标我方 1.3.6），并合入 1.3.7 的 R3 审计修复线。经三轮审计 + 修复复审 + 两轮真机验证后发布。

## 新增与改进

- **Stash 一等订阅格式**：订阅按客户端自动返回 Stash 配置（`?format=stash` 亦可），分流规则以 YAML 规则集下发（不再借 Clash 的 .mrs 规则集），无 Mihomo 专属的 DNS / 嗅探段；节点计数与实际下发一致。
- **入站分享地址四档**：每个入站可选 **自动 / 节点 IPv4 / 节点 IPv6 / 自定义域名**，分享链接、订阅下发与链式代理下一跳统一按此地址生成；选 IPv4 / IPv6 时节点地址变化自动跟随，节点无对应地址族时保存直接报错。
- **节点本月流量（网卡口径）**：节点页显示每个节点本月整机网卡流量（上行 / 下行），按面板时区自然月、逐小时统计；与订阅统计、转发计费口径分开，只作机器用量参考。
- **流量起算日标注**：订阅详情与「我的订阅」标注已用流量的起算时间（订阅创建或上次重置流量之时），显示为「<日期> 起已用 …」。
- **探测更可信**：探测请求带排队与超时预算，失败原因区分显示（超时 / 拒绝 / 节点无响应等）；节点重连、内核单独重启后自动重测；**只有定时探测轮计入掉线/延迟告警**，手动检测、保存配置后的重测不再误触发或误清除告警。
- **界面整理**：管理员不再有独立「监控」菜单，监控并入节点页（逐节点）与中转页（逐隧道质量）；普通用户的监控总览与授权方式不变。节点 / 入站 / 中转页数据 15 秒自动刷新。
- **订阅下载文件名**去掉站点名前缀。
- **订阅详情统计**增加分段条展示。

## 行为变更（BC）与口径变更

1. **分享地址校验收紧**：自定义分享地址与导入标准统一——尾点域名自动规范化后保存；含下划线、中文域名（未转 punycode）、回环地址的值不再接受。存量此类入站请改用规范主机名或 IP。
2. **节点地址不再可存结构字符**：节点地址（server_ip）含 `@`、`#`、逗号、空白或控制字符的值保存时直接拒绝；备份恢复与联邦同步遇到此类值会清空并在导入结果中披露。
3. **订阅端点地址校验全模式生效**：以前只校验「自定义」档，现在自动 / IPv4 / IPv6 档与中转入口的最终地址同样校验；不合格的端点在拉取时跳过并在面板日志留记录——回环 / 链路本地地址的节点将不再生成订阅端点（本地测试节点请改用 RFC1918 地址）。
4. **备份恢复的分享地址模式**：备份文件里非法的 `share_address_mode` 值恢复时按「自动」处理，并在导入结果中披露。
5. **本月流量计数口径修复**：网卡增删不再导致整机流量重复计入；新旧 agent 混跑期间，老 agent 节点在重启后的第一个统计窗口可能少计一小段（升级完成后即恢复正常口径）。
6. **节点地址不要带端口**：节点地址应只填主机名或 IP，不要写成 `host:port`——存量带端口的节点地址在订阅拉取时会被跳过并在日志留记录，把端口去掉即恢复。
